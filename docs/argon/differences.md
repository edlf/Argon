# Deliberate differences from the original game

Where argon chooses to behave differently from `default.xbe` (USA). These are on purpose, not porting gaps: what is
still missing or unchecked belongs in [argon/todo.md](todo.md). Each entry names where it lives in the code; the code's
comment there points back here.

Add an entry whenever a change makes argon differ from the game on purpose, and remove it if the game's behaviour is
restored.
